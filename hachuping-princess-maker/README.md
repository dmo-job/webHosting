# 하츄핑 프린세스 메이커 v3

아기 하츄핑을 1년(3월~2월) 동안 키워서 16가지 공주님 엔딩 중 하나를 만나는 7살용 육성 게임이에요.
글을 몰라도 할 수 있도록 모든 버튼과 대사를 소리로 읽어 줘요.

## 게임하는 방법

- **`play.bat` 더블클릭** → 주소창 없는 게임 창으로 열려요 (크롬이나 엣지 사용).
- 또는 `index.html`을 더블클릭해도 돼요.
- 창 오른쪽 위 ⛶ 버튼이나 **Shift+F**로 전체 화면이 돼요.
- 처음 한 번은 인터넷이 연결돼 있어야 글씨체와 이모지가 예쁘게 나와요.
- 저장은 브라우저 안에 자동으로 돼요. **같은 브라우저로 열어야** 이어서 할 수 있어요.

## 부모님 설정 (⚙️ → 버튼 2초 꾹 누르기)

목소리 켜기·끄기, 목소리 빠르기, 배경음악, 효과음, 미니게임 속도(느리게/보통/빠르게),
쉬는 시간 알림(20/30/45분), 저장 슬롯 지우기를 바꿀 수 있어요.

## 원작 도트 캐릭터 (이 PC에서만)

보내주신 참고 그림으로 만든 88칸 도트 캐릭터가 들어 있어요. 이 그림이 있는 캐릭터는 게임에서 원작 도트로 나와요.

- 하츄핑: 기본 모습(1기), 변신 폼 5가지(플로라·스타·베리·다이아·프린세스)
- 공주님 친구: 아름핑, 사뿐핑, 뽀니핑
- 참고 그림은 `assets/references/`, 만든 도트는 `assets/characters/`에 있어요.
- 하츄핑은 기본 옷이나 변신 폼을 입었을 때만 원작 도트로 나와요. 다른 옷을 입으면 옷이 보이도록 코드로 그린 도트로 바뀌어요.
- 설정 → 🌟 원작 도트에서 끄고 켤 수 있어요.
- 그림을 더 넣고 싶으면 `assets/references/`에 넣고 `tools/make_sprites.py`의 SOURCES에 한 줄 추가한 뒤 실행하세요.
  ```
  python tools/make_sprites.py
  ```
- 원작 그림이라 공유 링크에는 올리지 않았어요. 이 PC의 `play.bat` / `index.html`에서만 보여요.

## 캐릭터 그림 직접 넣기 (선택)

게임 속 캐릭터는 코드로 그린 그림이에요. 원작 그림을 그대로 쓰고 싶다면:

1. 원하는 캐릭터 그림을 PC에 저장해요. **배경이 없는(투명) PNG**가 가장 예뻐요.
2. 게임에서 ⚙️ 설정 → 버튼 2초 꾹 → **🖼️ 캐릭터 그림** → 캐릭터 아래 **📁 그림 넣기**.
3. 흰색처럼 한 가지 색인 배경은 자동으로 지우고, 그림 크기도 알맞게 줄여요.

- 넣은 그림은 **이 컴퓨터의 이 브라우저에만** 저장돼요. 파일로 남거나 다른 곳에 올라가지 않아요.
- 넣은 그림에는 옷 입히기와 표정이 보이지 않아요. 졸릴 때는 💤, 웃을 때는 ✨ 표시가 붙어요.
- `게임 그림만 쓰기`를 누르면 언제든 원래 그림으로 돌아가요. 🗑️ 빼기로 지울 수도 있어요.

## 배경 그림 넣기 (선택)

게임은 그림 없이도 돌아가요. 배경 그림 28장을 넣으면 활동, 모험, 행사 장면이 더 예뻐져요.
캐릭터는 게임이 직접 그리니까 **배경만** 만들면 돼요. (원작 캐릭터를 AI로 그리면 거절되거나 모양이 달라지기 쉬워요.)

### 방법 1. 무료 · 자동 (추천): Pollinations
키도 가입도 필요 없어요. 15초에 한 장씩 만들어서 28장에 8분쯤 걸려요.
```
python tools/generate_images.py
```
무료 토큰(auth.pollinations.ai에서 가입)을 쓰면 더 빠르고 워터마크가 없어요.
```
$env:POLLINATIONS_TOKEN="발급받은 토큰"
python tools/generate_images.py
```

### 방법 2. 무료 · 손으로: Gemini 앱 / Google AI Studio / ChatGPT / Bing Image Creator
`tools/image_prompts.md`의 프롬프트를 하나씩 붙여 넣고, 나온 그림을 적힌 파일 이름으로
`assets/images/`에 저장한 다음 이것만 실행하세요.
```
python tools/generate_images.py --scan
```

### 방법 3. API 키 (보통 유료)
- **Gemini**: Google AI Studio에서 키 발급. 이미지 모델은 결제가 연결된 계정에서만 돼요.
  ```
  $env:GEMINI_API_KEY="키"
  python tools/generate_images.py --provider gemini
  ```
- **OpenAI (GPT)**: platform.openai.com 키. 이미지 API는 유료예요.
  ```
  $env:OPENAI_API_KEY="키"
  python tools/generate_images.py --provider openai
  ```

그 밖의 옵션: `--only sc_dance,ballroom`(골라서 만들기), `--force`(다시 만들기), `--list`(목록 보기)
